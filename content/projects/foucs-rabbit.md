# Foucs-rabbit / 专注小萝卜

**把专注计时、宠物养成和学习记录放在一起的微信小程序**

[GitHub ↗](https://github.com/icey1287/Foucs-rabbit)

专注小萝卜是吉林大学 H5 课程设计项目。它把一段专注时间变成一个有开始、有结束、也有反馈的小任务：选择时长与陪伴宠物，完成计时获得金币，再用金币购买或升级宠物。

技术栈：`微信小程序` · `JavaScript` · `WXML / WXSS` · `微信云开发` · `Canvas` · `ECharts`

## 从计时到养成的循环

```text
选择专注时长与宠物
        ↓
倒计时 / 音乐 / 背景 / 陪伴语句
        ↓
完成专注 → 写入记录 → 累计时长与金币
                              ↓
                       购买、升级宠物
```

首页提供多档专注时长和宠物选择。专注页用 Canvas 绘制圆形时钟与剩余时间，支持暂停，并结合可切换的背景音乐、图片和陪伴语句营造学习氛围。

## 宠物不只是装饰

养成系统包含萝卜猫、萝卜狗以及不同成长阶段的形象。完成专注获得的金币可以用于购买和升级，宠物的等级又会影响下一次专注时展示的形态。

宠物和金币信息保存在云数据库中。首页读取当前拥有的宠物与等级，专注页接收选中的宠物信息，养成页负责购买、查看和升级，页面之间围绕同一份状态协作。

## 让学习时间留下记录

每次完成专注会写入专注时长、日期与时间戳，并更新累计时长和金币。统计页使用 ECharts 绘制学习时间趋势，包括按星期展示的统计和按月份展示的统计；历史记录页提供另一种回看方式。

计时结束后的反馈因此不止于一个弹窗：这段时间还会成为记录、图表和宠物成长的一部分。

## 页面与数据组织

| 页面 | 职责 |
| --- | --- |
| home | 选择时长和陪伴宠物 |
| focusing | 倒计时、Canvas 时钟、音乐与完成记录 |
| pet | 宠物购买、等级与成长状态 |
| info | 学习时间统计图表 |
| history / me | 历史记录与个人信息 |

项目使用微信云数据库保存用户、专注记录与宠物数据，使用云存储分发背景和音频资源。资源下载后保存到本地文件缓存，再次使用时先检查缓存文件，避免每次进入页面都重新获取。

这份课程设计把移动端交互、定时任务、音频控制、Canvas 绘制、数据可视化和云端存储串成了一条完整的产品路径。
