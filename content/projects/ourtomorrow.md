# OurTomorrow

**为两个人保留日常的小小空间**

[GitHub ↗](https://github.com/icey1287/OurTomorrow)

OurTomorrow 是一个以手机使用体验为中心的双人手账。它把即时状态、主动分享的位置和独立留言放在一起，让普通的一天也有一个可以被记下来的地方。

技术栈：`Vue 3` · `Vite` · `TypeScript` · `Pinia` · `TanStack Vue Query` · `NestJS` · `Prisma` · `PostgreSQL`

## 三件日常的小事

| 场景 | 交互 |
| --- | --- |
| 写下此刻 | 更新自己的状态与位置 |
| 了解对方的近况 | 查看对方最近一次主动发送的位置和更新时间 |
| 留下一张便笺 | 发送文字与一张照片，在便笺匣查看往来和未读状态 |

位置是主动分享的某一个时刻，而不是持续后台追踪。留言则是一张张独立的便笺，既可以表达当下，也可以稍后打开阅读。

## 轻量的双人设置

设置页围绕共同纪念日、首页扉页句子和当前使用者切换展开。空间名称、显示称呼、纪念日起点等由服务端配置提供，页面围绕同一个双人空间组织内容。

相比堆叠更多社交功能，这个项目把注意力放在最常发生的互动：我现在怎样、你最近在哪里，以及有句话想留给你。

## 前端、接口与持久化

```text
Vue 3 手机端页面
    ├─ Pinia：前端状态
    └─ TanStack Vue Query：接口数据
               ↓
          NestJS API
          ├─ Prisma → PostgreSQL
          └─ 地图服务代理 → 高德 Web 服务
```

前端使用 TypeScript 管理页面与接口类型，后端由 NestJS 提供业务接口，Prisma 管理数据库模型与迁移。地图查询经过 API 代理，服务密钥保留在后端。

## 开发与交付

仓库分别组织 Web、API 和基础设施配置，提供 OpenAPI 文档、类型检查、测试、生产构建、接口契约检查和端到端测试命令。部署使用 Docker Compose 与 Caddy，覆盖从本地开发到服务交付的完整路径。

这是一次从日常需求出发的全栈实践：让界面、数据与交互围绕一个很小但明确的使用场景工作。
